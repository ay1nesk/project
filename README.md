# HabitBot

**Telegram-бот для формирования и отслеживания привычек**

Полная документация проекта (идея, оценка, устав, экономика, стейкхолдеры) ведётся в [Wiki репозитория](https://github.com/ay1nesk/project/wiki). Этот README — краткая выжимка для быстрого знакомства с проектом.

## О проекте

HabitBot помогает пользователю формировать полезные привычки, устанавливать напоминания и отслеживать свой прогресс — прямо в Telegram, без установки отдельного приложения.

- **Проблема:** пользователи часто забывают о своих целях, пропускают выполнение привычек и со временем бросают их отслеживать.
- **Решение:** простой Telegram-бот, который позволяет создавать привычки, получать напоминания, отмечать выполнение и просматривать статистику.
- **Ключевой результат:** пользователь получает удобный инструмент для ежедневного отслеживания привычек и анализа прогресса без установки отдельного приложения.

## Целевая аудитория

- Студенты и школьники
- Молодые специалисты
- Пользователи Telegram, заинтересованные в самоорганизации и продуктивности
- Люди, которые хотят сформировать полезные привычки

## Цель проекта (SMART)

> Привлечь не менее 500 пользователей и добиться не менее 50 активных пользователей HabitBot в течение 3 месяцев после запуска MVP, реализовав основные функции создания привычек, напоминаний, отметки выполнения и статистики.

## Функционал MVP

- Создание привычек
- Напоминания о выполнении
- Отметка выполнения привычки
- Просмотр истории и статистики

**Срок реализации MVP:** 2–3 недели.

## Технологии

## Почему HabitBot

Идея выбрана из трёх рассмотренных вариантов (HabitBot, SplitBot, MusicBot) на основе экспертной оценки по критериям потребности, простоты реализации, потенциала пользователей, уникальности и возможности развития:

| Идея | Средняя взвешенная оценка |
| --- | --- |
| **HabitBot** | **4,70 / 5** |
| SplitBot | 4,03 / 5 |
| MusicBot | 3,73 / 5 |

HabitBot получил наивысшую и наиболее согласованную оценку экспертов, с явным преимуществом по трём самым весомым критериям. Подробности — на странице [Evaluation](https://github.com/ay1nesk/project/wiki/Evaluation).

## Классификация и ограничения

**Классификация:** малый, простой, краткосрочный монопроект по созданию цифрового продукта (технический со социальным компонентом).

**Ограничения (треугольник «Объём — Сроки — Стоимость»):** наиболее важное ограничение — объём. На первом этапе важно не перегружать проект дополнительными функциями и выпустить рабочий MVP в установленный срок.

**Подход к управлению:** Agile — требования к продукту могут изменяться после обратной связи от первых пользователей, поэтому разработка ведётся небольшими итерациями с регулярным тестированием.

Подробности — на странице [Concept](https://github.com/ay1nesk/project/wiki/Concept).

## Экономика проекта

**Модель монетизации:** freemium-подписка. Базовые функции — бесплатно, платная подписка Pro (расширенная статистика, неограниченное число привычек, экспорт данных) — 199 ₽/мес.

| Показатель | Значение |
| --- | --- |
| Фиксированные расходы | ≈ 2 700 ₽/мес |
| Переменные издержки на пользователя | ≈ 15 ₽/мес |
| Единовременные инвестиции на запуск | ≈ 105 000 ₽ |
| Точка безубыточности | ≈ 15 платящих подписчиков в месяц |
| NPV (3 года, ставка 18%) | ≈ +23 600 ₽ |

Идея экономически привлекательна на MVP-этапе (NPV > 0, точка безубыточности достижима). Полный расчёт — на странице [Concept](https://github.com/ay1nesk/project/wiki/Concept#экономика-проекта).
